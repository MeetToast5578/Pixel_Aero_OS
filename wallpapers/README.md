# Pixel Aero OS — Wallpaper Style Catalog

**Status:** The following wallpaper concepts have been prepared as individual PNGs, but binary file upload to GitHub remains outstanding. These filenames are upload targets, not live download links yet.

All sixteen themed variants have **1920×1080 pixel dimensions**, derived from *320×180 native-resolution* crops of a generated 4×4 style board and enlarged with nearest-neighbor filtering for crisp pixel-art edges. These are concept studies and should not be mistaken for native 4K wallpapers.
