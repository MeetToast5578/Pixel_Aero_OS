# Pixel Aero — Refined Pixel-Art Wallpapers

Sixteen AI-assisted recreations of the original low-resolution concept crops, preserving their pixel-art direction, scene themes and palettes. Detail has been newly generated; these are reinterpretations, not lossless restorations. Cropped caption bars have been removed.

The files below are native generated PNGs, without subsequent resizing. Their dimensions are recorded individually; they are not native 4K. The [original concepts](../README.md) remain available unchanged. Asset licensing remains undecided; these are concept references, not final-release OS assets.
