# Pixel Aero OS — Visual Reference Index

These are the intended reference filenames for the **Pixel Aero** art direction: Frutiger Aero atmosphere, genuine pixel-art structure, and **Glass Pixels** (dynamic liquid-glass interiors held within crisp pixel-art silhouettes).

> **Asset upload status:** The binary PNG reference pack has been prepared, but the images have **not yet been transferred into this GitHub repository**. The filenames below are the intended upload targets. Once the PNGs are uploaded, they can be embedded as a gallery.

| Expected file | Visual design purpose |
| --- | --- |
| `original-glassy-utopia.png` | Original selected desktop concept |
| `desktop-overview.png` | Daylight desktop with launcher, AeroBar, music and quick settings |
| `glass-pixels-materials.png` | Aero, Crystal, Frost and Water glass-material concept variations |
| `aerobar-launcher.png` | Launcher, search, taskbar and app actions |
| `ui-components.png` | Buttons, title bars, icons, menus, notification and widget reference |
| `wallpaper-daylight.png` | Full original eco-futuristic environment concept |
| `desktop-night.png` | Nighttime desktop style |
| `wallpaper-style-board.png` | Alternative themed wallpaper mood board |
| `wallpaper-preview-grid.png` | Quick comparison of sixteen standalone wallpaper styles |

All artwork is **conceptual, not screenshots of a working OS**. Source graphics may include illustrative generated dates or text. Actual live transparency and refraction must be implemented and demonstrated separately.

See [design identity](../docs/design-identity.md), [development plan](../plan.md) and [wallpaper catalog](../wallpapers/README.md).

**Design principle:** The glass moves; the pixels stay disciplined.
