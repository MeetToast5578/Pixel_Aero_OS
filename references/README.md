# Pixel Aero OS — Concept References

These images are **visual targets**, not evidence of a functioning operating system. They show the intended blend of Frutiger Aero atmosphere, intentional pixel-art geometry, and Glass Pixels: dynamically transparent, refractive liquid-glass interiors in pixel-structured UI frames.

> **Design principle:** The glass moves; the pixels stay disciplined.

## Implementer notes

- The generated concept art is illustrative and can contain noncanonical wording or imagined controls.
- Flat screenshots **cannot demonstrate genuine live transparency/refraction**; test this in Glass Pixels Lab and later, if feasible, KWin integration.
- Production UI assets should be hand-designed or carefully rebuilt, not blindly cropped from mockups.
- Maintain accessibility, a readable UI and performance fallbacks.
- See [design identity](../docs/design-identity.md) and [development plan](../plan.md).

## Asset / licensing status

These are concept and design reference files, not a polished shipping icon or wallpaper pack. Before distributing them as final OS assets, choose licenses and review third-party rights and usage requirements.
